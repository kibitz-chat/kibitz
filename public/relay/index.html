Kibitz

📡 No internet needed beta

Everyone on the same Wi-Fi, together — with no internet at all.

A plane, a cabin, an event with dead cell, an office with no guest internet. One device runs a tiny LAN hub; everyone else opens Kibitz on the same Wi-Fi and you're in a room together. No accounts, no servers, no signal — the video goes phone-to-phone across the network.

It's one download on one always-on-ish device — a laptop, a Mac, a Raspberry Pi — then everyone scans a QR once. The LAN hub is open source; the downloads and a short step-by-step setup live on GitHub:

Get the LAN hub on GitHub →downloads · setup · source

Note: these first binaries (v0.1.0) are an early preview — not yet tested on every OS, so expect rough edges and please report what breaks. The repo also builds from source in one command.

Tip: for a Wi-Fi with truly no internet (the hub's own hotspot, a dead-zone cabin), open kibitz.chat once on real internet first — it caches itself so it loads offline later.
